Гэта першая публікацыя. Яна ж — хуткі даведнік па магчымасцях markdown, даступных тут. Выдаліце яе, калі напішаце сапраўдную першую публікацыю.

## Блокі кода

Звычайны fenced-блок кода:

```ts
export function greet(name: string): string {
  return `Hello, ${name}!`;
}
```

## Табліцы і спісы задач

| Магчымасць                      | Крыніца                           |
| ------------------------------- | --------------------------------- |
| Табліцы, спісы задач, footnotes | стандартны markdown-канвеер Astro |
| Загалоўкі → зьмест старонкі     | `TableOfContents.astro`           |
| Пошук                           | На баку кліента, React            |

- [x] Content collection наладжана
- [x] Тэгі і пошук працуюць
- [ ] Напісаць сапраўдную першую публікацыю

## Загалоўкі становяцца зместам старонкі

Любы загаловак `##`/`###` на гэтай старонцы трапляе ў панэль «На гэтай старонцы» на шырокіх экранах, а бягучы раздзел падсвечваецца падчас пракруткі.
